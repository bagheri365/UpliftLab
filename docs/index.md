# UpliftLab documentation

UpliftLab compares heterogeneous treatment-effect estimators and decision policies in an **exploratory study** on the X5 RetailHero dataset. Distinguish observed associations, model-based estimates and causally identified effects. Causal identification has **not** been independently established.
