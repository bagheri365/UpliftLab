# Data handling

Do not commit raw datasets, customer records, derived features, or trained models.

Planned sources:
- X5 RetailHero: https://ods.ai/competitions/x5-retailhero-uplift-modeling/data
- ACIC 2016: https://jenniferhill7.wixsite.com/acic-2016/competition

Before modeling, document licensing/access constraints, assignment mechanism, outcome definition, treatment timing, and leakage risks. Keep downloads local under `data/raw/`.
